Getting Started

Odoo JSON API is a PHP library that provides a clean, type-safe wrapper around Odoo's new JSON-2 external API, introduced in Odoo 19. This new API replaces the legacy XML-RPC and JSON-RPC interfaces with a modern HTTP+JSON approach using API key authentication.

Type-Safe

Full PHP 8.3+ type declarations with strict types throughout. Leverages readonly classes, named arguments, and union types.

PSR Compliant

Built on PSR-18 (HTTP Client) and PSR-17 (HTTP Factories). Bring your own HTTP client or use auto-discovery.

Fluent Builder

Chainable request builder with where(), fields(), limit(), orderBy() and more.

Full CRUD

Complete support for search, read, create, write, unlink, count, fields_get, read_group, and custom method execution.

Error Handling

Typed exception hierarchy mapping HTTP status codes to specific exception classes for precise error handling.

Zero Config

Auto-discovers Guzzle or Nyholm PSR implementations. Just install a PSR-18 client and go.

Installation

Requirements

  • PHP 8.3 or higher
  • A PSR-18 HTTP client (e.g., Guzzle 7.5+)
  • Odoo 19+ instance with JSON-2 API enabled

Install via Composer

$ composer require obuchmann/odoo-json-api

If you don't already have a PSR-18 HTTP client installed:

$ composer require guzzlehttp/guzzle
Tip The library auto-discovers Guzzle and Nyholm PSR-7 implementations. If you use a different PSR-18 client, pass it explicitly to the Odoo constructor.

Quick Start

use Obuchmann\OdooJsonApi\Config;
use Obuchmann\OdooJsonApi\Odoo;

// Configure connection
$config = new Config(
    url: 'https://your-odoo-instance.com',
    apiKey: 'your-api-key',
    database: 'your-database', // optional if dbfilter is configured
);

// Create client
$odoo = new Odoo($config);

// Search and read partners
$partners = $odoo->searchRead('res.partner', fields: ['name', 'email'], limit: 10);

// Or use the fluent builder
$partners = $odoo->model('res.partner')
    ->where('is_company', '=', true)
    ->fields(['name', 'email', 'phone'])
    ->orderBy('name asc')
    ->limit(20)
    ->get();

Configuration

The Config class holds your Odoo connection details. It is a readonly value object.

use Obuchmann\OdooJsonApi\Config;

$config = new Config(
    url: 'https://your-odoo-instance.com',   // Base URL (trailing slash stripped)
    apiKey: 'your-api-key',                  // Bearer token for authentication
    database: 'mydb',                        // Optional: sent as X-Odoo-Database header
);

Direct Methods

The Odoo class provides direct methods for all standard operations:

Search & Read

use Obuchmann\OdooJsonApi\Domain;

// Search and read with optional domain filter
$domain = new Domain();
$domain->where('is_company', '=', true)
       ->where('country_id', '=', 14);

$companies = $odoo->searchRead('res.partner', $domain, fields: ['name']);

// Search for IDs only
$ids = $odoo->search('res.partner', $domain);

// Read specific records by IDs
$records = $odoo->read('res.partner', [1, 2, 3], fields: ['name', 'email']);

// Count records
$count = $odoo->count('res.partner', $domain);

Create, Update, Delete

// Create
$id = $odoo->create('res.partner', [
    'name' => 'New Partner',
    'email' => 'partner@example.com',
]);

// Update
$odoo->write('res.partner', [$id], ['name' => 'Updated Name']);

// Delete
$odoo->unlink('res.partner', [$id]);

Other Operations

// Get field definitions
$fields = $odoo->fieldsGet('res.partner', ['string', 'type']);

// Call any method on a model
$result = $odoo->execute('res.partner', 'custom_method', ['param' => 'value']);

Fluent Request Builder

Use $odoo->model('model.name') to get a fluent builder scoped to a specific Odoo model.

// Search and read with fluent API
$partners = $odoo->model('res.partner')
    ->where('is_company', '=', true)
    ->fields(['name', 'email', 'phone'])
    ->orderBy('name asc')
    ->limit(20)
    ->offset(0)
    ->get();

// Get first matching record
$partner = $odoo->model('res.partner')
    ->where('email', '=', 'user@example.com')
    ->fields(['name', 'email'])
    ->first();

// Find by ID
$partner = $odoo->model('res.partner')
    ->fields(['name', 'email'])
    ->find(42);

// Count
$count = $odoo->model('res.partner')
    ->where('active', '=', true)
    ->count();

// CRUD via builder
$id = $odoo->model('res.partner')->create(['name' => 'New']);
$odoo->model('res.partner')->update([1, 2], ['active' => false]);
$odoo->model('res.partner')->delete([1, 2]);

// Read grouped data
$groups = $odoo->model('res.partner')
    ->where('active', '=', true)
    ->fields(['country_id'])
    ->readGroup(['country_id']);

// Call custom method
$result = $odoo->model('res.partner')->call('my_method', ['arg' => 'value']);

Domain Filters

The Domain class builds Odoo domain filter expressions using a fluent interface.

use Obuchmann\OdooJsonApi\Domain;

$domain = new Domain();
$domain->where('name', 'ilike', 'test')
       ->where('active', '=', true)
       ->orWhere('email', '!=', false);

// You can also pass raw conditions to the constructor
$domain = new Domain([['active', '=', true]]);

Context

The Context class allows you to pass Odoo context parameters (language, timezone, custom keys) with your requests.

use Obuchmann\OdooJsonApi\Context;

// Create with initial values
$context = new Context(['lang' => 'fr_FR', 'tz' => 'Europe/Paris']);

// Or build it fluently
$context = (new Context())
    ->set('lang', 'de_DE')
    ->set('tz', 'Europe/Vienna');

// Merge additional values
$context->merge(['active_test' => false]);

// Use with direct methods
$partners = $odoo->searchRead('res.partner', context: $context);

// Or with the builder
$partners = $odoo->model('res.partner')
    ->context($context)
    ->get();

Custom HTTP Client

By default the library auto-discovers Guzzle or Nyholm. You can provide your own PSR-18 client:

use GuzzleHttp\Client as GuzzleClient;
use GuzzleHttp\Psr7\HttpFactory;

$httpClient = new GuzzleClient(['timeout' => 30]);
$factory = new HttpFactory();

$odoo = new Odoo($config, $httpClient, $factory, $factory);
PSR Standards The constructor accepts any ClientInterface (PSR-18), RequestFactoryInterface, and StreamFactoryInterface (PSR-17). When all three are provided, they are used directly. Otherwise, HttpClientFactory::create() fills in missing components via auto-discovery.

Error Handling

The library provides a typed exception hierarchy that maps HTTP status codes to specific exception classes:

use Obuchmann\OdooJsonApi\Exception\OdooException;
use Obuchmann\OdooJsonApi\Exception\AuthenticationException;
use Obuchmann\OdooJsonApi\Exception\NotFoundException;
use Obuchmann\OdooJsonApi\Exception\ValidationException;
use Obuchmann\OdooJsonApi\Exception\ServerException;

try {
    $partner = $odoo->read('res.partner', [99999]);
} catch (AuthenticationException $e) {
    // 401 or 403 - Invalid API key or insufficient permissions
} catch (NotFoundException $e) {
    // 404 - Model or endpoint not found
} catch (ValidationException $e) {
    // 400 - Invalid parameters
} catch (ServerException $e) {
    // 500+ - Server error
} catch (OdooException $e) {
    // Any other Odoo API error
    $e->getHttpStatusCode();  // HTTP status code
    $e->getErrorData();       // Raw error data from Odoo
}
ExceptionHTTP StatusDescription
AuthenticationException401, 403Invalid API key or insufficient permissions
NotFoundException404Model or resource not found
ValidationException400Invalid request parameters
ServerException500+Odoo server error
OdooExceptionAnyBase class for all exceptions

Architecture

Odoo (main facade)
 ├── Config (readonly value object)
 ├── HttpClient (PSR-18 based)
 │    ├── HttpClientFactory (auto-discovery)
 │    └── Response (readonly value object)
 ├── RequestBuilder (fluent API)
 │    └── Traits: HasDomain, HasFields, HasLimit, HasOffset, HasOrder, HasGroupBy, HasContext
 ├── Request (abstract base)
 │    ├── SearchReadRequest
 │    ├── SearchRequest
 │    ├── ReadRequest
 │    ├── SearchCountRequest
 │    ├── CreateRequest
 │    ├── WriteRequest
 │    ├── UnlinkRequest
 │    ├── FieldsGetRequest
 │    ├── ReadGroupRequest
 │    └── ExecuteRequest
 ├── Domain (filter builder)
 ├── Context (context values)
 └── Exception
      ├── OdooException (base)
      ├── AuthenticationException (401/403)
      ├── NotFoundException (404)
      ├── ValidationException (400)
      └── ServerException (500+)
API Endpoint Pattern All requests are sent as POST /json/2/{model}/{method} with a JSON body containing named parameters and a Bearer authorization header.
